# dsh-btw

在 **DeepSeek Harness 官方原生右侧栏**中开启多条并发、临时、多轮的侧边对话。

[English](README.md) · [MIT 许可证](LICENSE)

> 独立社区项目，与 DeepSeek、OpenAI、Anthropic 无隶属关系。当前适配目标是 **DSH 0.2.1-rc.2**。开发版本已进行自动化代码测试和真实 Host／模型／文件工具测试。按用户要求，界面点击与视觉验收留待后续实际使用；不将单元测试冒充界面验收。

## 使用规则

- 主输入框提交 `/btw`：新建空侧聊并立即冻结当前主上下文，不发起空模型请求。
- 提交 `/btw 你的问题`：新建侧聊并在其中发送问题，不把问题发给主代理。
- 展开原生侧栏，在“开始”页点击第四项“侧边对话”：新建空侧聊。
- **每次入口操作都新建标签页**，不复用、不覆盖已有侧聊。只有点击对应的旧标签页才能继续那条对话。
- 每个侧聊使用创建被 Host 接受时的主会话已提交上下文快照，加上自身后续问答；不会自动同步之后的主会话内容，也不会读取其他侧聊。
- 收起侧栏、切标签、切主会话、分栏、停靠和全屏切换，不销毁未关闭侧聊。
- “停止”只停止本轮；**明确关闭标签页**才会拒绝新输入、取消并排空执行、清除该侧聊历史和缓存。关闭失败会报告，并支持重试。
- 历史仅在 Host 内存中。网页刷新可重新连接同一 Host 中未关闭的侧聊；Host 完整退出或重启后历史失效，旧标签页不会暗中重新创建另一份上下文。

## 能力边界

- 支持在主代理继续运行时进行多轮问答、文件与网页工具调用；可用工具取自父会话权限允许的集合，不扩大权限。
- 当前隔离运行时不支持终端、后台任务、委派、团队控制、插件安装以及交互式问答工具。需要权限升级或审批的操作会拒绝，不会借主会话审批界面授权。
- 输入为文本；暂不支持附件、图片输入或原生全部交互卡片。回答使用安全 Markdown；工具详情以可折叠文本显示。
- 临时的是**对话历史**，不是工作区。文件修改和外部工具已经发生的副作用不会因关标签而回滚。工具自身产生的输出附件／超长结果暂存，遵循原工具的生命周期，不应被理解成操作系统级“所有痕迹清零”。
- 不保证清除模型服务商日志、用户复制内容、操作系统内存或磁盘痕迹。
- 禁用、升级或卸载插件也会使其内存侧聊失效，类似重启插件运行时。
- 调度适配固定兼容 rc.2：保留原工具 restriction、guard 和 pre/post/result 政策，私有挂载原生超时处理；不通用转发第三方 tools/execute 外层包装器。
- 若继承历史需要未挂载的插件消息解释器（例如特定图片 offload），创建会明确失败，不会悄悄丢历史或退回永久会话。父 preset 后续重配的完整语义尚未单独验收。

## 为什么不直接使用普通 fork 会话

普通 Agent 工厂会在 setup 前建立持久化会话；调用方遮蔽服务也不会改变工厂固定的依赖上下文。为了实现真正的内存历史，每条侧聊持有独立 Cordis 根和官方 AgentRegistry、SessionStore、SessionProjectionRegistry、AgentLoop，不挂普通历史存储、索引、会话日志上传或子代理结果回报机制。

仅桥接模型、工具、提示能力，并使用官方 scope 父链保留工具和策略边界。标准工具执行的目标仍是独立侧聊 Agent，而不是主 Agent。

原生 SessionProvider 校验其引用必须属于全局 Session pool。因此本插件不绕过校验，也不为复用渲染器把临时历史放回全局存储：侧栏外壳、标签、开始页入口都由官方渲染，标签内部采用主题一致的独立聊天正文和输入框。

## 本地开发与安装

需要 Node.js 22.19+ 与 pnpm。运行代码预构建在 `dist`，安装时不执行构建脚本。

```sh
pnpm install --ignore-scripts
pnpm check
```

`pnpm check` 检查语法、插件展示元数据和禁止的 Client 运行时导入，运行 node:test，再生成 Host／ModuleLoader Client 构建。

项目仓库：[pyh-pan/dsh-btw](https://github.com/pyh-pan/dsh-btw)，问题反馈：[GitHub Issues](https://github.com/pyh-pan/dsh-btw/issues)。

仓库已包含预构建运行文件，可直接从 GitHub 安装。下面的 `web` 请替换成实际 profile，例如桌面版使用的 `desktop`：

```sh
dsh plugin --profile web add github:pyh-pan/dsh-btw
```

也可以克隆仓库，通过 DSH 插件管理器安装本地项目目录。安装影响当前 profile 中所有会话。不要手工修改 profile 的依赖清单或组合补丁；若安装结果要求重新加载／重启，应按结果执行，不能仅凭刷新浏览器推断 Host 已更新。

## 隐私与销毁

- 不将侧聊正文写入插件 localStorage、临时 JSONL、普通 DSH 会话日志或搜索索引。
- 原生侧栏布局只保留标签／资源标识，不保存问答或上下文正文。
- 关闭后只留下有限的、无正文的标识墓碑，防止旧请求使历史复活。
- 同一创建／发送请求的网络重试幂等；新的创建请求总是对应新的侧聊。
- UI 与 `btw_manage` 工具调用同一 Host 服务，所有操作验证父会话身份；HTTP 仅接受已认证 owner 连接。
- 浏览器事件流只传本条侧聊内容，不传继承的主历史全文。
